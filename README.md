# Attack on Titan ODM Gear Simulator

A Unity game based on the ODM gear from Attack on Titan.

[Play the demo](https://ratweeb.itch.io/odm-gear)

## Setup

1. Install [Unity Hub](https://unity.com/download) and Unity **2022.3.25f1**.
2. Clone or download this repository.
3. Open the project folder in Unity Hub.
4. Wait for the assets to import, then press **Play**.

If packages are missing, check **Window > Package Manager**.

## Controls

- **WASD:** Move
- **Mouse:** Look around
- **Left click:** Fire left hook
- **Right click:** Fire right hook
- **Space:** Boost
- **Shift:** Sprint on the ground
